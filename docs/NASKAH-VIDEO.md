## Catatan isi

- Adegan demonstrasi memakai tangkapan layar aplikasi yang benar-benar dijalankan dari build release (`localhost:8080`), bukan tiruan.
- Kalimat tentang penyimpanan menyebut bahwa data formulir masih di memori, karena integrasi Cloud Firestore belum dipasang.
- Suara: Piper `id_ID-news_tts-medium` (Bahasa Indonesia, 22.050 Hz, model gratis). Musik latar tidak dipakai.
